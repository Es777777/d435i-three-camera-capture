# v1.0.0 首次公开发布：录像压缩与播放

公开版本号从 **v1.0.0** 开始。此前 v6、v7、v8.x 是本地开发迭代编号；历史测试名称和记录保留，不能据此判断公开发行版本。

## 录制格式

| 模式 | RGB | IR1 / IR2 |
| --- | --- | --- |
| 默认推荐 | H.264 CRF18、yuv420p、MP4，有损 | FFV1 灰度 AVI，无损 |
| 通用 MP4 | H.264 CRF18 MP4，有损 | H.264 CRF12 MP4，有损 |
| 原始无压缩 | RGBA AVI | Y800 AVI |
| 旧 FFV1 | FFV1 AVI，无损 | FFV1 AVI，无损 |

当前 Marker 三维位置由双红外图像计算，RGB 用于着色。默认模式保留原始红外像素，压缩 RGB；三路 MP4 会改变测量像素，其精度需另行验证。压缩率取决于画面纹理、运动和噪声，没有固定的每分钟体积承诺。原始无压缩在 1280×720@30 时三路约 166 MB/s，即约 10 GB/分钟。

每路视频独立编码，IMU 和帧索引独立写入。首次启动自动安装固定版本编码器；无需配置系统 FFmpeg。session.json 保存编码及有损流信息；frames.jsonl 保留设备时间、视频索引和位姿编号。

## 检查与播放

结束录像先排空写入、完成封装，再核对视频帧数，并解码首帧、中间帧和末帧。summary.json 记录逐文件时长、大小、编码和检查范围。默认抽样检查不等于逐帧完整检查。

工作台 **录像检查／转 MP4** 可选择已有 session：

1. 检查保存报告、帧索引、帧号缺口和视频解码；可勾选逐帧完整解码。
2. 导出到新的 mp4_playback 子目录，生成普通播放器可播放的 H.264 MP4，并逐帧检查输出。
3. 原始文件、位姿和帧索引保持不变，WAV 音轨独立保留。有损播放副本不能替代原始测量数据。

## 验证

沿用开发阶段 11 项自动检查，覆盖引导标定、保存门禁、本机标定后直接录制、位姿快照、录后结算、三机重建、录像完整性、IR 像素一致性、Windows MP4 解码和旧录像转换。最新保存测试使用 1280×720@30 合成图像，三路各 180 帧及高频 IMU；默认模式红外像素回读一致。

自动测试不代表真实相机曝光同步、长时间硬盘吞吐或人脸毫米精度已通过现场验收。详细开发记录见 [录像压缩实现与验证记录](v8.4录像压缩与播放.md)。
