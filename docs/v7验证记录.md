## 首次准备与发布包

`tools/verify_bootstrap.py` 在临时的中文 / 空格目录中复制干净源码和最终离线材料，将 PATH 限制为 Windows 系统目录，并注入无效 PYTHONHOME / PYTHONPATH，验证启动器独立准备环境。检查包括首次离线安装、重复启动不重装、并发准备拒绝、使用期间修复拒绝、损坏 Python 包拒绝，以及已有数据保留。成功后清理临时环境，结果保存在 `software/logs/bootstrap_verification.json`，详细日志在同目录的 `bootstrap_verification.log`。

最终依赖版本的这组检查全部通过：本机首次离线准备 284.63 秒（约 4 分 45 秒），重复环境准备 9.06 秒；首次过程中 PATH 中没有 Python，全程禁止网络下载。这是本机测试耗时，其他电脑会随磁盘、杀毒扫描和系统负载变化。

已验证根目录 BAT 的环境准备调用链。在线小包为 `releases/D435I_ThreeHost_v7.zip`，离线包为 `releases/D435I_ThreeHost_v7_offline.zip`（约 185 MiB）。两份 ZIP 均校验整体 SHA256、全部成员摘要及与当前源码的一致性，未包含录像、日志、运行环境、角色设置或测试图片。结果见 `software/logs/release_verification.json`。
