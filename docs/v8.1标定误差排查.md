# v8.1 标定误差排查

2026-10-18。用户反馈 RMS 3.06 px、最大 8.39 px，已确认使用原有 70% 三面凹槽模型。点表、比例和默认反光面内缩保持原定义；单凭总误差截图无法确定具体错误点或实物原因。截图的“C11 已确认（手动位置）”只表示最后一次选择，不是最大误差点的识别结果。

## 原因与修正

原有求解先用 RANSAC 获取可靠对应点并优化，再检查全部用户点：RMS 上限 1.5 px，单点上限 3 px。即使大多数点正确，一个补选点偏得较大也会导致整组拒绝保存。原界面只显示总误差，并且拒绝时丢弃逐点检查结果，无法让用户直接定位问题点。

v8.1 保留拒绝结果的诊断位姿与对应点误差，在右侧表格按误差排序，并在实拍和模型图中标红优先复核点。点击表格或“定位最大偏差点”可放大原始 IR1 对应位置。用户重新点击实拍贴片中心，其他点位保留；也可显式移除当前点并撤销。剩余点重新检查，不能绕过六点、非共面、朝向或误差限制。

诊断投影用橙色虚线显示，只供核对。诊断位姿使用 `diagnostic_only` 标志，不能作为已通过位姿保存或参与三机结算。用户点击仍以独立实拍亮点为依据；不按诊断预测位置自动调整坐标。

全图固定阈值 210 可能漏掉较暗贴片，退回手动位置容易引入中心偏差。吸附保留全图唯一亮点优先，新增点击附近背景中位数和 MAD 确定阈值的局部检测，需足够亮度对比、紧凑连通域、无边界截断且无近邻歧义才吸附。纯色、饱和区域、大面积反光或两个等距亮点不自动选择。全图发现歧义时不换阈值强行选一个。

如仍无法通过，“导出本次点位与画面”保存 ZIP，包括原始冻结 IR1、点表、相机内参、点击坐标、尺寸参数和检查结果。该文件结构与可用标定不同，不能直接加载为标定。用于下一步判断是中心定位、点号错误、实物与模型几何差异，还是相机参数问题。
