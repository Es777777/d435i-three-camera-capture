# D435i 三机人脸数据采集

三台 Windows 电脑各连接一台 RealSense D435i，采集 RGB、双红外、音频和 IMU；完成本机标定后直接录像，汇总时再做三机坐标结算、重建与融合。

当前版本 **v1.0.0（录像停止修复版）**。支持 Intel/AMD 64 位 Windows 10/11。

## 下载与启动

**[下载录像修复版完整在线包](https://github.com/Es777777/d435i-three-camera-capture/releases/download/v1.0.0-recording-fix/D435I_ThreeHost_recording_fix.zip)** · [所有发布版本](https://github.com/Es777777/d435i-three-camera-capture/releases)

1. 完整解压在线包，双击其中的 **`启动数采.bat`**。
2. 首次自动准备专用 Python、固定版本依赖和视频编码器，需联网下载约 220 MB。无需手动安装 Python 或修改系统 PATH。
3. 在工作台打开“采集与本机标定”。三台分别选择 Master、Slave 1、Slave 2。
4. 三台相机观察同一个固定标定物，各自完成或加载本机标定，即可录像。
5. 汇集三个完整 session，分别重建，再进行三机合成和回放。

从源码使用时，也可以双击仓库根目录的 `启动数采.bat`。完整操作见 [软件使用说明](software/README.md)。

本次修复停止按钮响应、保存阻塞及短暂音频溢出导致录像自动结束的问题；完整说明与验证边界见 [录像停止修复](docs/v1.0.0录像停止修复.md)。

## 当前功能

- **统一入口与环境准备**：采集、标定复核、重建、合成、录像检查均由工作台进入。
- **引导式模型对点**：原 70% 三面凹槽模型；当前点高亮、亮点吸附、放大、撤销、逐点误差诊断。
- **本机标定后直接录制**：每帧记录时间戳和位姿编号，三机结算在汇总阶段完成。
- **压缩录制**：默认 RGB H.264 MP4＋两路红外 FFV1 无损 AVI；可选三路通用 MP4。
- **保存状态检查**：独立视频和元数据队列、目录测速、计数核对、保存后首中尾解码检查。
- **旧录像转 MP4**：工作台“录像检查／转 MP4”可完整解码检查并导出播放副本，原件保留。
- **录后重建**：双红外被动双目、Marker 三角化、彩色点云、音频辅助时间对齐、三机融合。

## 录制格式

| 模式 | RGB | 两路红外 | 适用情况 |
| --- | --- | --- | --- |
| 默认推荐 | H.264 MP4，有损 | FFV1 AVI，无损 | 压缩彩色视频，保留红外测量像素 |
| 通用 MP4 | H.264 MP4，有损 | H.264 MP4，有损 | 体积和播放器兼容性优先，测量精度另行验证 |
| 原始无压缩 | RGBA AVI | Y800 AVI | 原始像素保存，约 10 GB/分钟（1280×720@30，三路合计） |
| 旧 FFV1 | FFV1 AVI，无损 | FFV1 AVI，无损 | 全无损压缩，CPU 开销较高 |

红外 FFV1 数据需要支持该编码的播放器，也可导出 MP4 播放副本。音频独立保存为 WAV。压缩率取决于画面纹理、噪声和运动，不保证固定文件大小。

## 使用边界

采集按**相机与标定物均固定**设计；移动机位需要重新标定。IMU 报警会使相应位姿失效，当前不支持连续移动机位的位姿恢复。

9-pin 硬件同步需要实际接线；主从模式回读、收帧正常和音频时间对齐都不能独立证明曝光同步。标定通过、软件测试通过不等于真实面部测量精度已验收。轨迹编号目前是几何跟踪编号，不能直接作为永久解剖点身份。

## 源码与验证

`software/` 是维护源码，`software/tests/` 是自动检查，`software/tools/` 包含环境准备、诊断和打包脚本。

环境准备后，在仓库根目录的 PowerShell 中执行：

```powershell
& .\software\.venv\Scripts\python.exe .\software\tools\run_checks.py
& .\software\.venv\Scripts\python.exe .\software\tools\build_release.py
```

测试覆盖标定交互、位姿快照、录后结算、录像完整性、无损红外像素、Windows MP4 解码、视频转换及三机重建。相机真实吞吐、曝光同步和面部精度需要现场实验。

个人采集数据、运行日志、专用运行环境和历史私人资料保留在本地，不包含在本仓库或发布包中。
